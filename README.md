# J7 Fitness 3D Website UI Demo

Premium frontend-only 3D animated website concept for **J7 Fitness, Raipur**.

## Run locally

```bash
npm run dev
```

Then open `http://localhost:5173`.

## Scope

This is a UI/UX demo only. It includes no backend, database, authentication, payments, booking system, CMS, CRM, API integration, or real form submission. CTAs and buttons use visual/demo interactions only.
